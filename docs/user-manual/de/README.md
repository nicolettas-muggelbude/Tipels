## Schnellstart

### GUI-Modus

```bash
tipels
```

Oder über das Anwendungsmenü: **System → Einstellungen → Tipels**

### CLI-Modus

```bash
# Hardware scannen
tipels scan

# Drucker installieren
sudo tipels install --model "MFC-L2700DN" --connection usb
```

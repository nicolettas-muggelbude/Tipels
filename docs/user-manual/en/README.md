## Quick Start

### GUI Mode

```bash
tipels
```

Or via application menu: **System → Settings → Tipels**

### CLI Mode

```bash
# Scan for hardware
tipels scan

# Install printer
sudo tipels install --model "MFC-L2700DN" --connection usb
```
